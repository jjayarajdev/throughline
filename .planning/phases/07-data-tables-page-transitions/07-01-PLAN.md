**DataTable.tsx** -- Generic table wrapper. Props interface:
```typescript
interface DataTableProps<TData, TValue> {
  columns: ColumnDef<TData, TValue>[];
  data: TData[];
  pageCount?: number;           // Total pages (server-side)
  rowCount?: number;            // Total row count for display
  pagination?: { pageIndex: number; pageSize: number };
  onPaginationChange?: OnChangeFn<PaginationState>;
  sorting?: SortingState;
  onSortingChange?: OnChangeFn<SortingState>;
  columnFilters?: ColumnFiltersState;
  onColumnFiltersChange?: OnChangeFn<ColumnFiltersState>;
  loading?: boolean;
  emptyIcon?: React.ReactNode;
  emptyTitle?: string;
  emptyDescription?: string;
  emptyCta?: React.ReactNode;
  toolbar?: React.ReactNode;    // Custom toolbar slot
}
```
- Uses `useReactTable` with `getCoreRowModel()`.
- When `pageCount` provided, sets `manualPagination: true`.
- When `onSortingChange` provided, sets `manualSorting: true`.
- When `onColumnFiltersChange` provided, sets `manualFiltering: true`.
- Renders: optional toolbar slot, then scrollable table container with sticky header, then pagination.
- Table container: `<div className="relative"><div className="pointer-events-none absolute right-0 top-0 bottom-0 w-12 bg-gradient-to-l from-background to-transparent z-10 sm:hidden" /><div className="overflow-x-auto rounded-md border">` -- the gradient scroll hint only visible on mobile.
- Table header: `<TableHeader className="sticky top-0 bg-background z-10 border-b">`.
- Loading state: render `pageSize` skeleton rows (default 10) using `<Skeleton className="h-5 w-full" />` in each cell.
- Empty state: render `<DataTableEmptyState>` with configurable icon/title/description/CTA.
- Use `flexRender` for all header and cell rendering.

**DataTablePagination.tsx** -- Bottom bar with page size selector and navigation.
- Shows "Rows per page" Select (10/25/50).
- Shows "Page X of Y" text.
- 4 navigation buttons: first, prev, next, last using `ChevronsLeft`, `ChevronLeft`, `ChevronRight`, `ChevronsRight` from lucide-react.
- Uses `table.getCanPreviousPage()` / `table.getCanNextPage()` for disabled state.
- Shows total row count if `rowCount` prop provided: "{rowCount} total".

**DataTableColumnHeader.tsx** -- Sortable header button.
- Props: `column: Column<TData, TValue>`, `title: string`, `className?: string`.
- If column not sortable, render plain text.
- If sortable, render a `Button variant="ghost" size="sm"` that calls `column.toggleSorting()`.
- Icons: `ArrowUp` when asc, `ArrowDown` when desc, `ArrowUpDown` (opacity-50) when unsorted.

**DataTableToolbar.tsx** -- Container for search, filter dropdowns, and filter pills.
- Props: `table: Table<TData>`, `filterableColumns?: { id: string; title: string; options: { label: string; value: string }[] }[]`, `searchColumn?: string`, `searchPlaceholder?: string`.
- Renders search `Input` with `Search` icon if `searchColumn` provided.
- Renders `DropdownMenu` per filterable column.
- Below filters, renders `DataTableFilterPills` for active column filters.
- "Clear all" button resets all column filters via `table.resetColumnFilters()`.

**DataTableFilterPills.tsx** -- Active filter display.
- Props: `table: Table<TData>`, `filterableColumns?: { id: string; title: string; options: { label: string; value: string }[] }[]`.
- Reads active filters from `table.getState().columnFilters`.
- Renders each active filter as a `Badge variant="secondary"` with X dismiss button.
- "Clear all" ghost button when 2+ filters active.

**DataTableEmptyState.tsx** -- Empty table state.
- Props: `icon?: React.ReactNode`, `title?: string`, `description?: string`, `cta?: React.ReactNode`.
- Defaults: title="No results found", description="Try adjusting your search or filters."
- Centered layout within a `TableRow` / `TableCell` with colSpan.

**index.ts** -- Barrel export of all 6 components plus re-export of table primitives.

IMPORTANT implementation notes:

- All components use semantic tokens (bg-background, text-muted-foreground, border) -- no hardcoded colors.
- DataTable generic types: `<TData, TValue>` propagated correctly.
- `ColumnDef`, `SortingState`, `PaginationState`, `ColumnFiltersState`, `OnChangeFn` imported from `@tanstack/react-table`.
