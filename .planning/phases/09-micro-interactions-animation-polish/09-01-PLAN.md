2. Create `apps/web/src/lib/motion-features.ts` — lazy-loaded domAnimation features for LazyMotion:
   ```typescript
   // Lazy-loaded framer-motion features (~15KB on demand, not in main bundle).
   // Usage: <LazyMotion features={loadFeatures} strict>
   export default function loadFeatures() {
     return import('framer-motion').then((mod) => mod.domAnimation);
   }
   ```
   This function returns a Promise, which is exactly what LazyMotion's `features` prop accepts for async loading.

3. Create `apps/web/src/lib/motion-config.ts` — shared transition presets:
   ```typescript
   /** Shared animation presets for consistent timing across the app. */
   export const DURATIONS = {
     fast: 0.15,    // Button hover/tap, focus glow
     normal: 0.2,   // Card hover, dialog entrance
     slow: 0.3,     // Page-level transitions (avoid exceeding this)
   } as const;

   export const TRANSITIONS = {
     /** Snappy for interactive elements (buttons, toggles). */
     snappy: { duration: DURATIONS.fast, ease: 'easeOut' as const },
     /** Smooth for entrance/exit animations (dialogs, sheets). */
     smooth: { duration: DURATIONS.normal, ease: [0.16, 1, 0.3, 1] as const },
     /** Spring for playful interactions (notification bell bounce). */
     spring: { type: 'spring' as const, stiffness: 400, damping: 25 },
   } as const;

   /** Stagger config for list animations (notifications, stat cards). */
   export const STAGGER = {
     container: {
       hidden: { opacity: 0 },
       show: {
         opacity: 1,
         transition: { staggerChildren: 0.05, delayChildren: 0.1 },
       },
     },
     item: {
       hidden: { opacity: 0, x: 20 },
       show: { opacity: 1, x: 0 },
     },
   } as const;
   ```

4. Update `apps/web/src/main.tsx` — wrap the app with MotionConfig for global reduced-motion support:
   - Add import: `import { MotionConfig } from 'framer-motion';`
   - Wrap `<RouterProvider>` (inside QueryClientProvider) with `<MotionConfig reducedMotion="user">`:
   ```typescript
   <QueryClientProvider client={queryClient}>
     <MotionConfig reducedMotion="user">
       <RouterProvider router={router} />
     </MotionConfig>
     <Toaster position="top-right" richColors closeButton />
     <ReactQueryDevtools initialIsOpen={false} />
   </QueryClientProvider>
   ```
   This makes ALL framer-motion components respect `prefers-reduced-motion: reduce` without per-component checks. Toaster and DevTools stay outside MotionConfig since they don't use framer-motion.

   NOTE: MotionConfig is a lightweight provider (~1KB) — it does NOT pull in the full framer-motion bundle. The heavy features are only loaded via LazyMotion in individual components.


   Key details:
   - `transition-all duration-150 ease-out` replaces `transition-colors` to cover transform + box-shadow
   - `hover:scale-[1.02]` — subtle 2% scale-up on hover (GPU-composited)
   - `hover:shadow-md` — shadow lift effect
   - `active:scale-[0.98]` — press-down feel on click
   - `motion-reduce:*` — Tailwind v4 utility that maps to `@media (prefers-reduced-motion: reduce)`, disables all transforms and shadow changes for accessibility
   - The `link` and `ghost` variants don't need exceptions — scale on text links looks natural and the 2% is subtle enough

3. Add `card-hover` CSS class to `apps/web/src/index.css` — pseudo-element shadow technique for 60fps performance:

   Add before the existing `/* Respect prefers-reduced-motion */` block:

   ```css
   /* Card hover lift — uses pseudo-element for GPU-composited shadow transition.
    * Direct box-shadow animation causes repaints (148ms). Opacity on pseudo-element
    * with pre-rendered shadow reduces to ~51ms. See: tobiasahlin.com/blog/how-to-animate-box-shadow/ */
   .card-hover {
     position: relative;
     transition: transform 0.15s ease-out;
   }

   .card-hover::after {
     content: '';
     position: absolute;
     inset: 0;
     border-radius: inherit;
     box-shadow: 0 8px 24px oklch(0 0 0 / 0.12);
     opacity: 0;
     transition: opacity 0.15s ease-out;
     z-index: -1;
     pointer-events: none;
   }

   .dark .card-hover::after {
     box-shadow: 0 8px 24px oklch(0 0 0 / 0.3);
   }

   .card-hover:hover {
     transform: translateY(-2px);
   }

   .card-hover:hover::after {
     opacity: 1;
   }
   ```

4. Extend the existing `prefers-reduced-motion` block in `index.css` to cover the new card-hover class:

   ```css
     }
   ```
