  ```
  grep -rn "rgb(\|rgba(" apps/web/src/pages/
  ```

  For each match found:
  - Replace `bg-gray-50` / `bg-gray-100` -> `bg-muted` or `bg-secondary`
  - Replace `bg-gray-900` / `dark:bg-gray-800` -> `bg-card` or `bg-background`
  - Replace `text-gray-400/500` -> `text-muted-foreground`
  - Replace `text-gray-700/800/900` -> `text-foreground`
  - Replace `border-gray-200/300` -> `border-border`
  - Replace `dark:border-gray-700` -> `border-border` (inherits dark mode)
  - Replace `bg-blue-600` -> `bg-primary`
  - Replace `text-red-*` -> `text-destructive`
  - Replace `text-green-*` / `text-emerald-*` -> `text-success`
  - Replace `bg-yellow-*` / `text-yellow-*` -> use StatusBadge or `bg-warning/10`
  - Replace `bg-purple-*` -> `bg-primary` (admin accent is primary in design system)
  - Hex values -> find the appropriate semantic token

  - Tailwind JIT safelist comments or enumerated literal strings for dynamic classes
  - StatusBadge internal color mapping (it maps status strings to semantic variants internally)
