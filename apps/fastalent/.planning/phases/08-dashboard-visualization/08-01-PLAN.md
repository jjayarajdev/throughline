**Step 2: Create AnimatedMetric component** at `apps/web/src/components/custom/AnimatedMetric.tsx`.

Props interface:
```typescript
interface AnimatedMetricProps {
  end: number;
  duration?: number;        // default 1.5s
  prefix?: string;          // e.g. "₹"
  suffix?: string;          // e.g. "%"
  decimals?: number;        // default 0
  separator?: string;       // default ","
  className?: string;
}
```

Implementation:
- Use `CountUp` from `react-countup` wrapped in a `<div ref={elementRef}>`.
- Use native `IntersectionObserver` (NOT react-intersection-observer library) with `threshold: 0.3`.
- Track visibility with `useState(false)`. When `entry.isIntersecting`, set `true` and `observer.disconnect()` to trigger once only.
- Respect `prefers-reduced-motion`: check `window.matchMedia('(prefers-reduced-motion: reduce)').matches` -- if true, set `duration={0}` to skip animation.
- Before the element scrolls into view, render a static `<span>` with the formatted end value (so the layout is stable).
- The `useEffect` for IntersectionObserver must have empty deps `[]` and return cleanup `() => observer.disconnect()`.
- Use a `useRef` initialized-flag to prevent React 18 StrictMode double-invoke from creating duplicate observers.

**All chart components share these patterns** (from research):
- Use ONLY named imports from recharts (never `import * as Recharts`).
- Wrap chart in `<ResponsiveContainer width="100%" height="100%">`.
- Tooltip `contentStyle`: `{ backgroundColor: 'hsl(var(--card))', border: '1px solid hsl(var(--border))', borderRadius: 'var(--radius-md)', color: 'hsl(var(--card-foreground))' }`.
- Tooltip `cursor`: `{ fill: 'hsl(var(--muted))' }` for bar/area charts.
- Axis `stroke`: `"hsl(var(--muted-foreground))"`, `fontSize: 12`.
- Primary fill: `"hsl(var(--primary))"`.
- Add `accessibilityLayer` prop to all chart root elements.
- Bar radius: `[4, 4, 0, 0]` for rounded top corners.

**Create a shared tooltip style constant** at the top of each chart file or in a local `_chart-theme.ts` helper (optional -- inline is fine too since there are only 7 files, but a `_chart-theme.ts` helper with `TOOLTIP_STYLE` and `AXIS_STYLE` constants would be cleaner).
