  <action>
Read the existing `apps/web/src/index.css` file first. Then append the following View Transition CSS rules AFTER the existing content (before any `@layer` directives if possible, or at the end):

```css
/* ── View Transitions (Phase 7) ────────────────────────────── */
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 0.2s;
  animation-timing-function: ease-in-out;
}

::view-transition-old(root) {
  animation-name: vt-fade-out;
}

::view-transition-new(root) {
  animation-name: vt-fade-in;
}

@keyframes vt-fade-out {
  to { opacity: 0; }
}

@keyframes vt-fade-in {
  from { opacity: 0; }
}

/* Disable View Transitions for users who prefer reduced motion */
@media (prefers-reduced-motion: reduce) {
  ::view-transition-old(root),
  ::view-transition-new(root) {
    animation: none !important;
  }
}
```

Use `vt-` prefix to avoid collision with existing shimmer/skeleton keyframe names.
Keep duration at 0.2s (short enough to not interfere with scroll restoration per research pitfall #5).
