Two approaches based on API support:
- **If the API supports offset-based pagination** (page/limit params): Switch from `useBrowseRoles` (infinite query) to a new `useQuery` with `{page, limit, ...filters}` and use DataTable with server-side pagination.
- **If the API only supports cursor-based pagination**: Use DataTable with client-side pagination. Fetch a page of data and let TanStack Table handle pagination on the loaded data. Keep the "Load more" pattern for fetching additional batches.

Since `useBrowseRoles` uses `useInfiniteQuery` with cursor-based pagination, and changing the API is out of scope (NFR-03: no backend changes), use client-side pagination on the loaded data:
- Keep `useBrowseRoles` as-is with infinite query.
- Flatten pages: `const allRoles = useMemo(() => data?.pages.flatMap(p => p.items) ?? [], [data])`.
- Pass `allRoles` to DataTable with `manualPagination: false` (TanStack Table handles pagination locally).
- This means client-side sort/filter too (consistent -- don't mix client pagination with server sort).
- Add built-in sort/filter row models: `getSortedRowModel()`, `getFilteredRowModel()`, `getPaginationRowModel()`.

New structure:
```tsx
<Sheet open={open} onOpenChange={setOpen}>
  <SheetTrigger asChild>
    <button className="relative rounded-full p-2 ..." aria-label="Notifications">
      <Bell className="h-5 w-5" />
      {unreadCount > 0 && <span className="absolute ...">{badge}</span>}
    </button>
  </SheetTrigger>
  <SheetContent className="overflow-y-auto sm:w-[400px] p-0">
    <SheetHeader className="border-b px-4 py-3">
      <div className="flex items-center justify-between">
        <SheetTitle>Notifications</SheetTitle>
        {unreadCount > 0 && <Button onClick={markAllRead}>Mark all read</Button>}
      </div>
    </SheetHeader>

    {/* Tab bar: All / Unread */}
    <div className="flex border-b">
      <button onClick={showAll} className={cn(tab active styles)}>All</button>
      <button onClick={showUnread} className={cn(tab active styles)}>
        Unread {unreadCount > 0 && <Badge variant="secondary">{unreadCount}</Badge>}
      </button>
    </div>

    {/* Notification list */}
    <div className="divide-y">
      {filteredNotifications.map(n => (
        <button key={n.id} onClick={() => handleClick(n)} className={cn(
          'w-full px-4 py-3 text-left hover:bg-accent/50',
          !n.isRead && 'bg-accent/20'
        )}>
          <div className="flex items-start gap-3">
            {!n.isRead && <span className="mt-1.5 h-2 w-2 rounded-full bg-primary shrink-0" />}
            <div className="min-w-0 flex-1">
              <p className={cn('text-sm', !n.isRead && 'font-medium')}>{n.title}</p>
              <p className="mt-0.5 text-xs text-muted-foreground line-clamp-2">{n.body}</p>
              <p className="mt-1 text-[10px] text-muted-foreground">{formatRelative(n.createdAt)}</p>
            </div>
          </div>
        </button>
      ))}
    </div>

    {/* Footer */}
    <div className="sticky bottom-0 border-t bg-background px-4 py-2 text-center">
      <Link to={notificationsPageUrl} viewTransition onClick={() => setOpen(false)}>
        View all notifications
      </Link>
    </div>
  </SheetContent>
</Sheet>
```

Key improvements over current dropdown:
- `Sheet` handles focus trap, Escape-to-close, overlay backdrop, scroll locking.
- No manual click-outside listener needed.
- 400px width on desktop, full-width on mobile (Sheet default).
- Tab filtering (All / Unread) with local state.
- Unread dot uses `bg-primary` (teal) instead of hardcoded `bg-blue-500`.
- Proper shimmer `Skeleton` for loading state instead of text "Loading...".

Keep `formatRelative` utility function as-is (works well).
